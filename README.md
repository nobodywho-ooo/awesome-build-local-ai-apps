# Inference libraries

## React Native

- [NobodyWho](https://github.com/nobodywho-ooo/nobodywho) - Inference engine that lets you run LLMs locally and efficiently on any device.
- [React Native ExecuTorch](https://github.com/software-mansion/react-native-executorch) - provides a declarative way to run AI models on-device powered by ExecuTorch
- [Runanywhere](https://github.com/RunanywhereAI/runanywhere-sdks) - Production ready toolkit to run AI locally
- [Cactus Compute](https://github.com/cactus-compute/cactus) - Quantization, kernels, runtime and inference engine for mobiles, wearables, smart home and robots.
- [React Native AI](https://github.com/callstackincubator/ai) - On-device LLM execution in React Native with Vercel AI SDK compatibility
- [react-native-litert-lm](https://github.com/hung-yueh/react-native-litert-lm) - High-performance on-device LLM inference, powered by LiteRT-LM and Nitro Modules
